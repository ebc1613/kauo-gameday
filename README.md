# KAUO Game Weekend Traffic

Auto-updated dashboard of traffic at Auburn University Regional Airport (KAUO) on Auburn home-football weekends, with projections for upcoming games.

**Live page:** https://ebc1613.github.io/kauo-gameday/

This repo holds only the published page. A nightly job rebuilds it from ADS-B receiver data and pushes `index.html` here.

Built with help from AI (Claude). It is a prototype, and mistakes are possible. Questions: ebc0045@auburn.edu
